# 统计与访问控制

v0.15.0 将页面分为「运行概览」「过滤规则」「访问控制」。概览不再重复显示规则重载卡片，订阅管理和重新加载统一在过滤规则页面操作。

## 清零统计

在概览统计下方点击「清零统计」，同时清零已观察请求、已拦截请求和当前链路的诊断计数。比例从同一时刻重新计算；规则域名数、当前代理、规则配置、最近拦截和效果检测不随之删除。

命令由现有采集进程处理，收到回执后页面显示完成；不重启 DNS、代理或采集器。清零前尚未完成的查询不会把应答计入新周期。同一次开机内采集进程重启会保留新周期，路由器重启后重新计数。组件未就绪时不假装清零成功。

## 查看与管理域名

在「访问控制」中：

1. 点击「查看最近拦截」，临时记录五分钟、最多三十个域名，重复域名汇总次数，显示 A/AAAA 和最近时间。可按域名搜索。记录仍只在内存中，停止、到期或配置变化后清空，不保存客户端地址或完整浏览记录。
2. 点击记录的「检查并放行」，先核对当前规则及实际影响范围，再加入待应用。名单不会因为查看或搜索而立即改动。
3. 在自定义规则中选择放行或拦截，每行输入一个域名，也支持粘贴 HTTP/HTTPS 网址；各最多一百项。搜索、类型筛选、移除均在同一页面。
4. 修改完成后点击「应用访问控制」，统一处理规则并同步当前接入。关闭保护时可以先保存，之后开启时生效。批量任务失败尝试恢复两份旧名单；遇到并发外部修改则保留恢复记录，不覆盖其他设置。

过滤规则/DNS 和访问控制分别有待应用批次。为防止一份旧选择覆盖另一份更改，有一个批次未应用时，另一类可查看但暂不能编辑；先应用或撤销即可。私人名单不会写入浏览器持久缓存，离页前有未应用更改会提示。

## 规则范围

v0.17.0 查询结果会列出与当前已应用输出摘要一致的命中来源。新下载但未应用的快照不参与归因，丢失、过期或无法核对的来源明确显示暂不可确认；不会向查询结果添加含令牌的订阅地址。

命中规则后可直接临时放行 10 分钟或 1 小时，影响范围与永久放行相同。路由器独立计时，到期尝试恢复；失败保留状态并在退避后重试，不把失败显示成已恢复。关闭保护不会重新启用网络，下一次开启前处理过期条目；路由器重启后临时条目失效。临时放行和常规批量修改不能同时提交。

每条域名规则包含其子域；当前后端不能在父域拦截下悄悄精确放行某个子域。查询会显示真正命中的父域及放行范围，例如「ads.example 及其所有子域」。直接输入更小范围而无法生效时会停止应用并提示先查询，不自动扩大权限。放行与拦截名单不能范围重叠，同一域名切换类型会移除旧类型。撤销自定义拦截后，订阅仍可能拦截该域名；放行只移除 AdZero 的限制，其他插件的独立规则仍可能生效。

计数是采集到的 DNS 请求及拦截应答，不是网页广告个数。加密 DNS、绕过路由器、设备缓存或没有新广告查询时，数据可能不增加。

参考 AdGuard Home 的「查询记录 → 检查 → 自定义规则」交互，见 [官方 FAQ](https://github.com/AdguardTeam/AdGuardHome/wiki/FAQ) 和 [DNS 过滤规则说明](https://adguard-dns.io/kb/general/dns-filtering-syntax/)。AdZero 继续使用自己的轻量域名后端，没有安装或替换成 AdGuard Home，也不承诺支持其全部高级过滤语法。
