# v0.21.2 — 修复代理切换后的 DNS 设置应用

NaiLink 切换到 PassWall 后，如果已应用的国外组为并发，而 PassWall 使用 Xray DNS，兼容性预检会拒绝迁移。旧版即使把国外组改为“单一＋备用”，后续分流预检仍读取旧设置，使修正操作也被阻止。

- DNS 和分流预检现在读取同一份待应用计划；分流目标与计划不符时仍拒绝，真正的配置冲突和不兼容组合继续受保护。
- 新配置先完成预检，再进入原有事务、迁移和失败恢复流程。保留 PassWall 的 Xray／Sing-box 引擎；不会暗中改为 TCP DNS 或把国外并发降级为单一。
- 当前接入卡以新鲜的活动代理检测为准；旧恢复记录或旧观察样本不能把新代理标记为“规则已同步”。迁移未完成时显示“代理接入待同步”，并解释已应用 DNS 的兼容性限制。
- 原代理的设备检测结果不能证明新接入已通过，接入同步完成前暂停效果检测。

PassWall 的 Xray／Sing-box DNS 当前仍只支持国外“单一＋备用”；国内可并发。国外并发仍要求受支持的原生 TCP DNS 模式及真实可用的本机 SOCKS5 端口。不能为解决显示问题而跳过接入校验。

详见[审计与验证](AUDIT_0.21.2.md)和[验证摘要](evidence/v0.21.2/summary.json)。本轮对用户路由器只读取状态、配置开关与任务错误，没有应用草稿、修改配置、切换代理、升级或重启服务；隔离测试不等于生产迁移验收。
