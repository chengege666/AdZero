# AdZero v0.6.2 界面与交互

## 信息顺序

菜单与品牌名称统一为 AdZero。顶部状态带提供当前状态和主开关；下一行将规则域名、当前接入、终端验证分成三个概览卡片。规则更新与横向接入检查并排，设备信息合并到“设备与诊断”，和代理明细一起默认折叠。

桌面限制内容宽度为 1360px，减少空白并保持阅读距离；小于 520px 时，三个指标改为横向摘要列表，避免代理名称在窄卡片中断行。手机的开关独立成行，更新按钮占满卡片宽度。

使用低饱和绿色、清楚的文字层级和局部留白；移动端自动堆叠。CSS 限定在 `.az-root`，保留宿主 LuCI 导航。系统字体和本地 SVG 不需要外部字体、图标服务或前端框架。Phosphor 图标的 MIT 许可随包安装。

## 首次打开与状态读取

LuCI load 立即返回加载状态，render 创建可见页面后单独读取 ctl status。读取完成前显示占位符并禁用启停、更新；错误时保留重新检测入口。首次返回不抢夺焦点，之后每次操作仍重新读取真实状态。没有使用旧快照冒充当前运行结果。

probe 改用已有 ucode 模块，一次 UCI 游标、一次 procd 快照和一次 /proc 进程名扫描替代重复 uci/ubus/jsonfilter/pidof 命令。仍现场读取，不使用可能过期的状态缓存；backend 的规则有效性、解析器运行和所有权检查保持原样。

原生 LuCI 对数组中的 null 会生成文字，对标量字符串会按 HTML 处理。视图通过 el() 将内容规范为无空值的文本数组，同时保留有效数字 0；错误及服务器文字不进入 innerHTML。

## 状态和操作

- 开关表示实际读取到的后端配置；点击后保持原状态并显示等待信息，重新读取 ctl 状态后才更新。
- 开启、关闭、更新期间锁定所有操作，阻止重复提交；关闭也明确告知会恢复原有设置。
- v0.6.1 手动操作遇到其他会话占锁时，后端最多等待 30 秒；后台同步不与手动操作排队竞争。未知结果仍通过重新检测确认，界面不提前切换状态。
- 命令成功但最终状态不符合预期，仍显示失败。失败后重新检测当前状态；状态读取中断则显示“结果暂时无法确认”，提供重新检测。
- 错误信息使用文本节点，默认折叠。成功提示留在当前页面，避免依赖容易错过的短时通知。
- 操作完成后恢复键盘焦点；不抢占页面其他区域的焦点。诊断和代理列表的展开状态保留。
- 多代理冲突、AdGuard Home 占用或不支持的 DNS 模式显示原因并禁用开启；本插件拥有的异常配置仍提供“关闭并恢复”。
- “规则已载入 / 已接入”与“终端效果已验证”分开。没有真实查询数据就不显示今日拦截次数或受保护设备数。

## 可访问性和主题

主开关使用 `role="switch"` 和 `aria-checked`；按钮具有可见文字，装饰图标不重复朗读。交互区域最小高度 44px，提供可见键盘焦点，支持减少动态效果偏好。浅色说明文字在状态卡片上的对比度大于 4.5:1。

支持系统深色偏好及常见宿主的 dark/data-theme/data-darkmode 标记；显式浅色标记优先。没有这些标记的第三方主题仍需逐一验收。

## 本地预览

```sh
python3 scripts/preview_ui.py
# 打开 http://127.0.0.1:8765/
node tests/test_view.cjs
```

预览加载正式的 overview.js/CSS，但以隔离的 ctl 替身模拟启停、延迟和失败，不连接路由器。默认的 66,425 条规则来自用户提供的 v0.5.3 状态快照，仅供布局验证，不写入正式界面。顶部工具栏仅在预览中出现，可模拟 5 秒的首次读取，确认页面无需等待状态请求。

可选的宿主样式放在忽略目录 `artifacts/ui-preview/theme/css/cascade.css` 和 `fonts/`；未提供时使用浏览器基础样式。预览服务只绑定 127.0.0.1，只开放列明的资源。可选的 SDK 原生 DOM 放在 artifacts/ui-preview/native-dom.js，存在时优先加载，用于核对 LuCI 的实际节点行为。Argon 样式、字体及 SDK DOM 副本不进入源码发行包。

浏览器验证应覆盖：桌面、窄屏和深色；空白/未知状态；启停、更新、失败与重试；展开详情后刷新；键盘操作；真实 DOM 的 disabled 属性。LuCI 会把布尔 false 写成 disabled="false"，因此启用的控件必须省略该属性，不能写 false。
