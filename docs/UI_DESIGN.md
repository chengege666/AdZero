# AdZero v0.8.1 界面与交互

## 信息顺序

菜单与品牌名称统一为 AdZero。顶部状态带提供当前状态和主开关；下一行将规则域名、当前接入、终端验证分成三个概览卡片。主状态下方提供暂停时长和操作入口；概览卡片后优先提供域名查询与放行，规则更新与横向接入检查放在后面。代理兼容、固件/CPU/软件包等设备诊断区不再渲染；CLI status 保留排障数据，首页保留必要的错误、冲突和恢复入口。

桌面限制内容宽度为 1360px，减少空白并保持阅读距离；小于 520px 时，三个指标改为横向摘要列表，避免代理名称在窄卡片中断行。手机的开关独立成行，更新按钮占满卡片宽度。

使用低饱和绿色、清楚的文字层级和局部留白；移动端自动堆叠。CSS 限定在 `.az-root`，保留宿主 LuCI 导航。系统字体和本地 SVG 不需要外部字体、图标服务或前端框架。Phosphor 图标的 MIT 许可随包安装。

## 宿主主题边界

Argon 2.4.3 的 header::after 在顶栏下方绘制 2rem 装饰背景。真实页面中标题比这一背景底部高出约 12px，之前的预览只有样式而缺少外壳结构，未覆盖该问题。现在针对 `.main-right > header.bg-primary ~ #maincontent .az-root` 预留同等 2rem 空间；不移动宿主导航、不抬高插件层级。插件内部标题条改为 div，避开宿主对 header 标签的全局样式。

完整外壳预览复现修复前 12px 重叠；修复后桌面品牌与检测按钮分别位于装饰底部以下 20px/22px，手机为 14px 以上。普通外壳不匹配该选择器，无额外顶部偏移。

## 首次打开与状态读取

首次进入时，LuCI load 立即返回加载状态，render 创建可见页面后单独读取 ctl status；读取完成前禁用修改。返回菜单时，当前标签页同一登录会话最近 5 分钟的概览先行显示，注明「上次状态」，再后台读取真实结果。核对前禁用修改；失败保留概览、错误和重试入口。快照过期、损坏、重新登录或禁止浏览器存储时，正常走实时读取。首次返回不抢夺焦点，之后每次操作仍重新读取真实状态。

probe 改用已有 ucode 模块，一次 UCI 游标、一次 procd 快照和一次 /proc 进程名扫描替代重复 uci/ubus/jsonfilter/pidof 命令。后端仍现场核验规则有效性、解析器运行和所有权；前端快照只用于展示，不替代检查。

原生 LuCI 对数组中的 null 会生成文字，对标量字符串会按 HTML 处理。视图通过 el() 将内容规范为无空值的文本数组，同时保留有效数字 0；错误及服务器文字不进入 innerHTML。

## 状态和操作

- 开关表示实际读取到的后端配置；点击后保持原状态并显示等待信息，重新读取 ctl 状态后才更新。
- 开启、关闭、更新期间锁定所有操作，阻止重复提交；关闭也明确告知会恢复原有设置。
- v0.6.1 手动操作遇到其他会话占锁时，后端最多等待 30 秒；后台同步不与手动操作排队竞争。未知结果仍通过重新检测确认，界面不提前切换状态。
- 命令成功但最终状态不符合预期，仍显示失败。失败后重新检测当前状态；状态读取中断则显示“结果暂时无法确认”，提供重新检测。
- 错误信息使用文本节点，默认折叠。成功提示留在当前页面，避免依赖容易错过的短时通知。
- 操作完成后恢复键盘焦点；不抢占页面其他区域的焦点。错误信息可按需展开。
- 多代理冲突、AdGuard Home 占用或不支持的 DNS 模式显示原因并禁用开启；本插件拥有的异常配置仍提供“关闭并恢复”。
- “规则已载入 / 已接入”与“终端效果已验证”分开。没有真实查询数据就不显示今日拦截次数或受保护设备数。

## 可访问性和主题

主开关使用 `role="switch"` 和 `aria-checked`；按钮具有可见文字，装饰图标不重复朗读。交互区域最小高度 44px，提供可见键盘焦点，支持减少动态效果偏好。浅色说明文字在状态卡片上的对比度大于 4.5:1。

支持系统深色偏好及常见宿主的 dark/data-theme/data-darkmode 标记；显式浅色标记优先。没有这些标记的第三方主题仍需逐一验收。

## 本地预览

```sh
python3 scripts/preview_ui.py
# 打开 http://127.0.0.1:8765/
node tests/test_view.cjs
```

预览加载正式的 overview.js/CSS，但以隔离的 ctl 替身模拟启停、延迟和失败，不连接路由器。默认的 66,425 条规则来自用户提供的 v0.5.3 状态快照，仅供布局验证，不写入正式界面。预览包含 Argon 顶栏、延伸背景及 maincontent 容器，可切换普通外壳和侧栏占位。顶部工具栏仅在预览中出现，可模拟 5 秒的首次读取，确认页面无需等待状态请求。

可选的宿主样式放在忽略目录 `artifacts/ui-preview/theme/css/cascade.css` 和 `fonts/`；未提供时使用浏览器基础样式。预览服务只绑定 127.0.0.1，只开放列明的资源。可选的 SDK 原生 DOM 放在 artifacts/ui-preview/native-dom.js，存在时优先加载，用于核对 LuCI 的实际节点行为。Argon 样式、字体及 SDK DOM 副本不进入源码发行包。

浏览器验证应覆盖：桌面、窄屏和深色；空白/未知状态；启停、更新、失败与重试；标题/检测按钮与宿主装饰区的边界；键盘操作；真实 DOM 的 disabled 属性。LuCI 会把布尔 false 写成 disabled="false"，因此启用的控件必须省略该属性，不能写 false。

## v0.7.0 日常排障

域名/网址输入支持 Enter 查询，结果区明确区分命中、个人已放行、未命中和查询失败。命中时先显示实际规则及完整放行范围（含子域），按钮名为「放行此范围」。不推断注册域，不因命中子域而猜测放行整个站点。输入变化立即清除旧结果，防止对着旧范围操作。

个人名单按需展开，每项提供「撤销放行」。应用和撤销使用带类型的 adzero RPC，不向浏览器开放任意 shell 参数。执行结束后重读 ctl status，核对规则状态和名单；命令成功而状态不符也不能显示成功。

暂停时显示预计剩余分钟和「立即恢复 / 保持关闭」。暂停期间关闭查询、名单变更和更新规则，避免用户编辑不存在的运行规则。每 5 秒仅在暂停状态读取后台；后台独立完成到期恢复，关闭网页也会继续。离开插件页面停止该轮询，普通开启状态不持续轮询。恢复失败显示可操作提示。

本地预览的查询样例为 login.ads.example；命中 ads.example。示例只控制内存中的状态，不调用路由器。新增控件沿用局部配色、键盘焦点和移动布局，不添加诊断面板。

v0.7.1 在暂停轮询确认状态已改变时清除旧操作提示，避免自动恢复后仍显示“已暂停”。未取得新状态前不提前清除。

## v0.8.0 规则库与菜单返回

新增「运行概览 / 过滤规则」两页导航。内部切换保留现有概览与输入；重新进入 LuCI 菜单只缓存必要展示数据，不缓存订阅地址、私有令牌、个人名单或设备清单。规则页每次打开仍重新核对列表，期间保留已有行并禁止编辑，不先清空成“没有规则”。

规则页分为已添加订阅、自定义表单和规则库。每项提供独立开关、下载校验数量、校验时间和行内删除确认；数量不作为命中次数。预置卡片提供用途、来源主页和添加入口，已添加的卡片不重复提交。自定义表单明确名称、HTTPS URL 和三种可选格式。保护关闭时也可保存选择，成功提示明确“开启保护后应用”；暂停时先恢复或保持关闭再编辑。

规则操作以随机回执提交后台，浏览器每两秒只读核对进度，完成后重读真实状态和选择。没有预先切换开关，也不以“已提交”当成成功。返回同一标签页会恢复任务结果查询。服务端错误不把下载日志或私有地址返回界面。更详细语义见 [RULE_SOURCES.md](RULE_SOURCES.md)。

预览服务的规则库 JSON 可通过 `ADZERO_UCODE` 对 `scripts/source_transform.uc` 传入 `{"action":"catalog"}` 生成到 `artifacts/ui-preview/source_catalog.json`；静态源文件和域名数仅供隔离界面验证。

v0.8.1 修正匿名订阅的回滚并保护未提交的外部 UCI 修改；界面布局和 CSS 与 v0.8.0 相同，继续使用该版隔离预览图片。
