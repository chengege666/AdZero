# v0.22.0：统一安装与正式发布

OpenWrt、ImmortalWrt、iStoreOS 共用一个正式版本和安装入口。用户无需选择品牌专用版、ARM64 版或 Beta。插件本体仅保留一份 all IPK 和一份 noarch APK，由本机包管理器自动选择；原生依赖仍按固件与 ABI 匹配。

- 原生 APK 清单优先于残留数据库路径，修复迁移后错误识别包管理器的问题；运行状态与安装、卸载使用一致判断。
- 安装预检包含原生依赖求解；缺失依赖先准备，再调用旧版恢复。拒绝替换已有系统包、版本回退或混用 ucode ABI。
- iStoreOS 的已验证原厂依赖合并到同一发行版内部，按精确版本、修订号、target 与 ABI 自动补齐；已有完整版 tcpdump 保持原样。
- 首次安装保持保护关闭，升级保留原开关。恢复记录、真实配置冲突和操作锁保护继续保留；卸载增加原生包归属、依赖及恢复完成检查，保留已安装依赖且不锁定其后续版本更新。
- 入口兼容 curl 和固件自带 wget。所有安装器、应用包及原厂依赖继续校验 SHA-256。
- 在线更新只选择正式数字版本，跳过草稿与所有预发布版本。旧版本下载地址保留供恢复追溯。
- 首页、在线安装、兼容、维护和问题排查文档统一为同一入口。

推荐带 LuCI 的 24.10 / 25.12 系列；其他版本取决于本机运行库和原生依赖，不能跨固件强制装包。SDK 构建、软件包预检及隔离测试不代表每台真实设备的代理、LAN 或 IPv6 路径均完成现场验收。本次未升级、重启或切换用户在线路由器。
