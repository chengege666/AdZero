# AdZero Logo

![AdZero Logo](images/adzero-logo.png)

## 设计

深绿色盾牌代表网络保护，中央留白的 **Z** 对应 AdZero 的 Zero。图形不依赖文字，便于在 GitHub 首页、项目介绍和插件图标中使用。

- 主色参考：`#217B65`，延续现有界面的绿色。
- 文件：[adzero-logo.png](images/adzero-logo.png)。
- 格式：透明背景 PNG，1254 × 1254 像素。
- README 展示尺寸：104 × 104 像素。
- 留白：四周保留适当空间；保持比例，不拉伸。
- 深浅背景均可使用；Z 的留白会显示背景颜色。

本次将 Logo 用于 GitHub README，已发布的路由器安装包与 LuCI 页面资源未更换。
