# v0.20.5 — 统一插件 Logo

插件页头此前使用了通用“盾牌打勾”图标，与 README 中已经确认的“Z 字盾牌”不一致。本版直接复用已确认的 PNG 原图，统一插件、README 和在线文档的品牌图案。

- 页头改用随包安装的 Logo，不依赖外部图片请求；去掉旧图标的绿色底框，保留原图比例。
- 为图片预留尺寸，适配桌面与手机，升级后使用新的静态资源版本参数。
- 补齐打包文件清单和本地预览路由；文档检查核对三处 Logo 图片字节一致，界面检查确认页头加载本地图片。

主要修改 `overview.js`、`overview.css`，新增 `logo.png`，同步打包清单、预览脚本、回归用例和版本说明。过滤规则、DNS 与代理运行逻辑沿用 v0.20.4。

验证包括 372 项界面断言、17 项打包/交付测试、5 项文档测试、三个官方 SDK 的构建与实际包内检查，以及发行包的 6 组安装器交付检查。桌面、360px 手机和深色外观已用实际生产页面在本地预览中检查，截图使用模拟数据，不连接路由器。详细记录见[验证摘要](evidence/v0.20.5/summary.json)。

升级后按 Ctrl + F5 刷新页面。若仍看到旧图标，核对终端安装版本和页面版本，不需要为更换 Logo 调整 DNS 或代理设置。
