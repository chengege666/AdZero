# v0.18.2 紧凑布局与 DNS 操作完善

本轮按使用截图统一压缩四个页面的留白，规则库恢复双列卡片，并补齐 DNS 增强页的地址编辑和测试入口。后端广告规则、代理接入、网络配置事务保持原有实现；未连接或修改用户路由器。

## 界面调整

- 页面边距、区块间距、导航、统计卡片和表单统一收紧。普通桌面按钮保持至少 34 像素，触摸设备仍保留 44 像素操作区域。
- 规则库改为双列独立小卡片：名称与分类在顶部，简短说明居中，主页与添加操作在底部。保留「全部／未添加」筛选和统一待应用流程；窄屏改为单列。
- 增强页把空设备规则区放在增强过滤下方，减少左侧空白；已有设备时让编辑区独占一行。说明按需展开，状态异常直接显示。

## DNS 编辑与测试

- 增强页直接展示实际保存的国内、国外 DNS 地址，提供共享 DNS 编辑器；每组最多八个 IP、标准 53 端口。首条优先，其他为备用。
- 地址「保存到待应用」后统一应用；端口、开关和设备规则用底部「保存增强设置」。自动分流关闭时，地址只是保存，不会隐式启用代理 DNS 接管。
- 未暂存、待应用或增强设置未保存时禁止测试旧配置，并显示对应操作提示。收起再展开保留尚未暂存的输入。
- 测试结果只有在保存地址和国外 SOCKS5 端口与该次测试相同时才展示耗时；变化后提示需重测。后台测试更新只替换结果区域，不打断编辑焦点。
- 后台外部配置变化会更新未编辑的表单；有本地编辑时保留输入，由既有保存冲突检查处理。

## 修改文件与验证

- `overview.js`、`overview.css`：紧凑布局、双列规则卡片、内嵌 DNS 编辑及测试状态。
- `tests/test_view.cjs`：新增 17 条交互断言，总计 327 条，覆盖未保存测试拦截、暂存应用、旧结果失效和后台更新。
- `scripts/ui_preview.js`：模拟保存地址和测试结果，供实际生产视图的浏览器验收使用。
- `docs/DNS_ENHANCEMENTS.md`、在线文档、README、版本与安装入口同步。

验证证据见 [evidence/v0.18.2](evidence/v0.18.2/)。浏览器使用生产视图和 LuCI DOM，RPC、统计、DNS 耗时均为模拟数据；SDK 和隔离测试不替代真实路由器验收。
