# AdZero v0.23.3

修复切换代理或 NaiLink 内核后，关闭请求因等锁或恢复失败而丢失、后台提前停止的问题。

- 先保存关闭请求，再等待操作锁；失败后后台继续恢复，页面刷新后仍显示「正在关闭并恢复」。关闭完成前阻止新的开启和规则应用。
- 保留恢复所需的 DNS 辅助服务到恢复完成；即使 UCI 开关已关闭，也能继续完成遗留恢复。最终停止后台时先释放操作租约。
- 区分 AdZero 自己造成的 NaiLink 待应用状态和用户的新编辑，保留 DNS、路由、规则文件、全局选项、节点、群组及原生服务设置的冲突保护。记录仅保存摘要，不保存节点凭据。
- 必要的 NaiLink 原生恢复按应用／恢复两个阶段限次，不循环重启；已经确认载入原配置时避免再次重载。保留用户选择的内核及停止状态，不重启路由器。
- 同步在线排障说明；继续共用一份 IPK 和一份 APK，不新增安装渠道或大型依赖。

验证边界：v0.23.2 真机换核验收曾复现 sing-box 重载未确认；本次新增关闭恢复路径使用原生 OpenWrt 运行时和隔离故障回归验证。现网 mihomo 的接入、运行状态与操作锁仅作只读核对，本轮未部署程序或制造断网故障，不将其记为新版三个内核的完整现网验收。
