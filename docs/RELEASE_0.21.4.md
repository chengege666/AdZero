# AdZero v0.21.4 · 中文菜单安装与 LuCI 在线更新

**状态：待官方 SDK 构建与真实路由器验收。** 仅在 GitHub 发布含 SDK 匹配包的 Release 后，才能按此文操作。

## 本版改进

- 将版本号从「运行概览」标题右侧移到 AdZero Logo 旁；点击可展开在线更新检查。
- 自动检查 GitHub 官方 Release，有新版本时以提示点展示，列出版本及 SDK 兼容结果。
- 升级前先校验官方 install.sh 的 SHA-256 digest，并运行只读 --check，继续核对目标固件 ID、完整版本、target、OPKG/APK 架构和安装包 SHA-256。
- 确认升级后启动后台任务，不需要 SSH；使用原来的安装锁、依赖预检、配置备份和恢复流程，遇到异常不自动重复安装。
- 新增中文菜单安装：一键安装/自动升级、安装后不启用、只读检查、安全卸载与退出。默认安装入口命令不需要填写版本号。
- 修复原安装器仅因 DISTRIB_ID 不是 OpenWrt 就提前拒绝的逻辑；只接受已经通过相应 SDK 构建并出现在发行清单中的具体组合，禁止跨固件强装。
- 修复 OpenWrt 24.10.8 官方 BusyBox 的 `tr '[:upper:]' '[:lower:]'` 转换异常，该环境可能把 OpenWrt 误转换成 OwenWrt；改用显式 ASCII 大小写转换并加入官方 ash 回归。
- 同步 OpenWrt 官方仓库 `coreutils-timeout` 测试依赖的最新 SHA-256 固定值，已和官方 Packages.gz 索引核对；只用于隔离测试环境，不改变 AdZero 的实际过滤规则。

## 兼容范围

本版没有宣称为所有 iStoreOS 或 ImmortalWrt 提供包。仍需相应厂商 SDK 编译、ABI 验证和 LAN 过滤验收。当前开发者已完成的 SDK 验证组合为 OpenWrt 24.10.8 x86/64 IPK、25.12.5 x86/64 APK、25.12.5 rockchip/armv8 APK；新版必须由这些 SDK 重新构建才可发布。

## 首次进入新版

1. 通过 GitHub 的无版本号菜单安装命令（root SSH）选择安装/升级至已发布的 v0.21.4。
2. 安装完进入「服务 → AdZero」，点击左上 Logo 旁边的版本号。
3. 出现更新时先检查结果，点击「立即更新」，核对目标后再次确认。
4. 期间可能短暂重载 DNS 和代理；完成后刷新页面，确认显示的版本与已安装软件包一致。

## 安全边界

只连接官方 GitHub HTTPS；不执行浏览器给出的任意命令、URL 或脚本。版本与 SHA 校验结果短时有效且一次性使用。下载失败、固件未匹配、校验不一致、后台任务不确定时停止升级并保留已有恢复记录。在线更新不是 OpenWrt 系统升级或刷机。
