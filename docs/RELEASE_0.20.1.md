# v0.20.1 — 交互反馈与规则应用诊断

本版强化整个插件的操作反馈，并补全规则应用失败时的原因提示。沿用 v0.20.0 的 DNS、代理接入与恢复逻辑，不为开启更多规则替换代理引擎或放宽规则校验。

## 变化

- 卡片、列表、导航、开关统一悬停反馈；卡片轻微抬升、列表轻微位移，按钮有按下反馈。鼠标移出恢复，布局尺寸不随动画变化。
- 编辑、删除使用图标与明确按钮边框；删除使用独立警示色。规则库的添加按钮和已添加标识更清楚；禁用控件不响应点击或悬停位移。
- 触屏保持操作目标大小；键盘焦点清晰；尊重系统减少动态效果设置。没有增加动画依赖、鼠标跟踪或后台动画任务。
- 编辑订阅地址时提前阻止完全相同的地址。不同列表的域名重叠仍允许应用，合并去重；大量列表提示仅为建议。
- 下载、格式、重复项与容量上限使用固定错误类型。下载／校验失败时给出本批第几个启用订阅；任务仅返回经校验的数字位置，不回传订阅名称、URL 或日志。
- 同步在线文档中的交互说明、应用失败处理及规则上限。

## 关键文件

- `overview.css`、`overview.js`：全局交互、按钮层级、重复地址预检、订阅位置提示。
- `progress-lib.uc`、`sources.uc`、`usr/share/rpcd/ucode/adzero`：固定失败分类、校验进度及受限 RPC 元数据。
- `tests/test_batch.py`、`tests/test_view.cjs`、`scripts/check_rpc.py`：批量失败事务、草稿保留及回执隐私检查。
- `docs/site/content/rules.html`、`dashboard.html`、`docs/RULE_SOURCES.md`：在线与开发文档。

## 验证与范围

556 项 Python 测试、347 项 UI 回归、5 项文档测试通过。三个官方 SDK 目标构建及各 59 个载荷文件检查通过，六种实际交付安装器场景通过。结果见 [验证记录](evidence/v0.20.1/summary.json)。隔离测试覆盖 14 份重叠列表正常应用、完全相同地址拒绝、下载失败、格式失败及 50 万域名上限；失败不提交所选配置。RPC 检查拒绝无效索引并排除额外字段。界面使用实际生产代码与模拟后端检查浅色、深色和窄屏。

用户提供的 v0.20.0 任务回执确认：失败发生在 validating 阶段，预检合计超过 50 万域名，尚未提交这批更改；不是 DNS 设置冲突或域名重叠错误。v0.20.1 补齐此前缺失的容量错误提示，保持现有上限：单文件 25 MB、单列表及最终结果 50 万域名。超过上限的相同选择仍需精简后才能应用，不自动停用用户的列表。容量累积超标不表示当前列表格式错误。

没有操作或升级用户路由器。真实设备的新版启停与网络验收尚未进行。
