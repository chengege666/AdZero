# v0.20.3 — 明确规则草稿、保留真实冲突保护

修复批量规则应用中的两类已复现问题：空选择只在日志中报错、统计元数据更新使未修改的草稿被误判冲突。规则页分开展示后台选择与草稿，重载按钮只处理已应用配置。

## 变化

- 空方案返回固定原因 `empty_ruleset`，前端就地提示并阻止提交；单条停用、移除和批量应用共用校验。保护关闭时保存空选择、存在有效手动拦截项时仅使用手动规则仍可通过，不自动启用默认订阅。
- 配置版本使用规范化后的语义 SHA256，忽略明确的下载大小、校验计数、时间和验证状态元数据。保留订阅身份、名称、URL、实际格式、启用状态及过滤、DNS 和其他受保护选项；预检结束后、正式提交前用新游标再次核对。真实冲突保留草稿，不自动重基或覆盖，并展示可核对的差异。
- 规则页同时显示「已应用」和「待应用」数量。下方按钮改为「重载已应用规则」，有草稿时不可用，直接调用也不能暗中提交草稿；统一应用保留独立入口。
- 容量预检纳入未修改的启用来源及手动拦截项，记录完整、未知或超限状态。缺少可验证快照时先补齐检查；无法计数的来源不作为零。在线新增/启用/替换、需要重建的重载及用户选择后的完整启动，在相关检查通过后才进入重建。未知格式会给出 `source_capacity_unknown`，保留现有配置。
- 25 MB 文件/输出限制和 50 万域名上限不变。候选计数未扣除放行及父域优化；它是预检口径，最终载入数以运行概览为准。

## 修改范围与验证

主要文件：`sources.uc`、`source-cache.uc`、`progress-lib.uc`、`ctl`，以及 `overview.js`、`overview.css`；新增事务、缓存和界面回归用例，同步使用文档。

最终源码通过 579 项 Python 测试、366 项界面断言、5 项文档测试及 68 项实际 rpcd/ubusd 检查；OpenClash、PassWall 隔离运行检查通过。三个官方 SDK 完成构建，每包核对 59 项载荷文件及权限，发行包完成 6 项安装器交付检查。源码摘要在完整回归、实际运行检查与三个构建中一致，见[验证记录](evidence/v0.20.3/summary.json)。桌面与 360px 手机预览核对了空草稿、已应用/待应用数量及按钮状态，图中使用模拟数据。

预检不是 adblock-fast 的完整隔离 dry-run：原生格式无法独立识别时明确停止在线重建，既有输出的证明复用路径仍保留。最终后端输出格式、字节与代理适配检查继续执行，不承诺任意订阅或任意数量均能加载。

开发过程不连接或修改用户路由器；本地 OpenWrt 运行时与代理隔离测试不等于实机网络验收。交接包中的原始日志与私密订阅不进入公开发行内容。
