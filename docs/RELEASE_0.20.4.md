# v0.20.4 — 补齐重建预检，兼容旧恢复记录

修复深度审计中复现的三个问题：部分规则变更先重建后发现预检失败、旧版统计字段阻碍恢复，以及页面误清除真实冲突。

## 变化

- 在线修改名称、停用或移除订阅时，先核对现有输出能否直接复用。无法复用则在提交配置和停止后端前检查剩余来源；失败保留原配置及正在运行的后端。可证明未变化的名称或未启用项目修改仍直接复用，不增加下载或重建。
- schema 1 规则恢复记录、schema 2 后端缓存兼容旧版有效统计字段。规范化只忽略明确的下载大小、域名计数、检查时间和校验状态，不放宽对真实设置及未知选项的冲突保护。恢复缓存继续检查配置和处理后文件摘要，未应用的新快照不会被自动标成已应用。
- 已确认配置冲突或仍在进行的操作不会被页面自动判为应用成功。草稿、原始版本及差异提示继续保留，正常延迟回执完成后的自动确认仍可使用。
- 同步在线手册；没有新增运行依赖，DNS 路径和代理选择沿用现有配置。

## 修改与验证

实现主要修改 `sources.uc` 和 `overview.js`，新增事务、缓存和界面状态回归；版本、安装器及文档一起更新。详见[审计记录](AUDIT_0.20.4.md)。

最终源码通过 585 项 Python 测试、369 项界面断言、5 项文档测试及 68 项实际 rpcd/ubusd 检查；OpenClash 和 PassWall 隔离运行检查通过。三个官方 SDK 完成构建，每包核对 59 项载荷文件及权限，发行包完成 6 项安装器交付检查。详见[发行验证记录](evidence/v0.20.4/summary.json)。完整回归、运行检查与构建使用同一源码摘要。

开发期间没有连接或修改用户路由器，本地运行时、代理隔离测试及 SDK 构建不等于实机网络验收。
