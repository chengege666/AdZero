# AdZero v0.23.2

修复 NaiLink 切换 sing-box／mihomo 后，AdZero 重载等待无法结束、关闭恢复只能依赖整机重启的问题。

- 重载完成按运行版本、当前内核就绪状态、DNS／路由配置与规则文件共同核验，允许已完成的请求跨内核确认；不丢弃未确认的请求。
- 正在切换的内核不再当作已停止；恢复期间保留仍可能使用的规则文件。仅旧 API 明确缺少字段时使用兼容接口，传输或授权失败不会误判成 dae。
- 后台同步期间可排队关闭；等待锁和内核切换均有上限与进度提示，保护状态只在完成核验后更新。
- 操作锁增加 ucode 内置的内核租约，无新增依赖。活跃子任务继承租约，控制进程异常退出不会被抢锁；已确认退出的孤儿操作可安全回收，未知锁及外部文件继续保护。
- 显式关闭时，旧版无法证明完成的重载记录可以在核对配置所有权后，至多针对同一管理进程恢复一次 NaiLink 原生服务；核对进程身份变化后才恢复配置。后台同步不会因此重启代理。
- 保留外部编辑冲突、严格 DNS、下载校验和停止内核不自动拉起的保护，并同步在线排障文档。

现场只读检查：设备安装 v0.23.0、NaiLink 0.6.60-1；检查时 AdZero 已关闭、dae 运行、操作锁释放。历史日志存在重载未确认记录，故障中的完整旧恢复记录已不在设备上。隔离测试用于复现切换与丢失回执；不将其表述成现网内核切换验收。
