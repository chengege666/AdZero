# AdZero v0.23.1

修复在线检查仅依赖 GitHub API、遇到偶发 HTTP 403 或连接异常就无法继续的问题。

- API 不可用或元数据无效时，从同一个官方安装入口只解析固定正式版本和 SHA-256。不会执行未校验的入口脚本，不接受第三方 URL，也不要求用户提供 Token。
- 保留正式安装脚本 SHA-256、本机依赖预检、一次性确认、15 分钟有效期、并发锁及升级失败不自动重试。摘要冲突不会通过后备来源绕过。
- 更新面板标明后备来源；失败时分别显示 API 与官方入口状态。网络、下载或摘要失败不再统一提示固件不兼容。
- 统一升级说明，清理排障页仍要求选择旧 Beta／品牌专用渠道的过时指引。

现场只读检查曾收到 API HTTP 403，随后同一设备检查恢复为可更新且兼容。没有证据把该次 403 唯一归因为请求配额；路由器未执行升级、代理切换或服务重启。
