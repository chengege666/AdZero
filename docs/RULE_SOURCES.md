# 过滤规则管理

「运行概览」处理日常开关、暂停和误杀排查；「过滤规则」管理订阅。预置规则库只是快捷入口，用户也可以添加符合格式的自定义 HTTPS 来源。列表显示名称、地址、启用状态、下载校验后的数量和最近校验时间。删除订阅需要在该行确认，先加入待删除选择；名称、地址和格式也可编辑后暂存。个人放行名单不受影响。

## 支持格式

| 格式 | 示例 | 约束 |
| --- | --- | --- |
| 域名列表 | `ads.example.com` | 每行一个 ASCII/punycode 域名，支持注释和空行 |
| Hosts | `0.0.0.0 ads.example.com` | 每行一个域名映射，支持常见本机头部；不接受复杂别名 |
| 基础 DNS Adblock | `\|\|ads.example.com^` | 只接受这种基础域名语法和注释；高级例外、修饰符、正则及网页元素规则会拒绝整份导入 |

域名不接受 IP、下划线和通配符。订阅地址只接受 HTTPS 的标准端口，不接受账号密码或片段；查询参数可以包含订阅令牌，地址仅保留在路由器配置中，不写入浏览器概览快照或任务回执。每份最多 25 MB / 50 万域名，最多管理 30 个拦截订阅；实际后端产物最多 50 万域名，开启及应用时校验。关闭保护时可以分别保存列表，下次开启仍须通过合并产物检查。既有后端其他格式保留原行为，不会伪装成已通过上述导入校验。

规则库包括 HaGeZi Light / Normal / Pro、anti-AD 和 AdAway。来源链接指向各自维护项目，列表内容会随上游变化；选择和使用需遵守对应规则许可。每项的数量可能重叠，合并去重及个人放行后，以概览有效域名数为准。相同系列通常选一项即可，叠加会增加下载、处理和内存成本。

## 应用与恢复

规则增删、编辑、开关与自动分流选择先保留在当前页面内存；内部两个页签共享草稿。点击“应用并重新加载”统一提交，或“撤销更改”恢复页面上的已应用选择。选择时没有写 RPC、下载和重载；关闭保护时可先选择并应用配置，下次开启时生效。刷新或离开前浏览器会提醒，未应用草稿不持久保存。

应用使用固定类型的 `settings_apply` RPC。修订哈希及原分流值防止旧页面覆盖新配置；请求内容存入 0600 临时文件，工作进程只持有路径，公开回执不包含订阅地址或参数。变化来源统一预检，规则改变时统一重建后端与同步代理，未变则跳过。NaiLink 同批规则及分流修改共用一次代理重载；其他适配器的分流切换沿用原生恢复/应用流程，可能重载两次。

“重新加载”有草稿时统一应用，没有草稿时核对已应用配置，内容未变则跳过重建和重载。“更新订阅”主动下载全部已应用且启用的来源；有待应用修改时先应用或撤销。预检正文通过按来源快照交给后端复用，更新后内容相同时不再重建。缓存缺失、异常或自定义 curl 参数会回到正常下载。下载始终严格验证 HTTPS 证书。详见 [性能与操作说明](RULE_APPLY_PERFORMANCE.md)。

更新检查允许 adblock-fast 遗留的数字 `file_url.size` 统计；其余未提交用户编辑仍会明确拒绝，不自动保存或清理。批量失败会尝试恢复全部选择及原分流设置，页面保留草稿；恢复未确认时禁止新写操作。

没有 AdZero 格式字段的订阅，尝试识别域名、Hosts、基础 DNS Adblock，并记录数量及检查时间，不改原 URL 或原生格式设置。v0.10.3 修复 CNAME Trackers 这类纯域名列表的识别：对后端 ASCII 域名处理本已丢弃的前导连字符、下划线记录，计入排除数量，不再导致整份列表无法独立计数。页面显示有效域名数、排除记录数和检查时间；注释、空行、重复域名不计入无效记录。Hosts、Adblock 和其他无效内容仍保持严格检查，不通过删除规则语法制造域名。

无法识别的旧格式保留后端处理，明确标为「格式未识别」，并提示更新订阅可重新校验；不会填入合并总数或假数量。未检查的启用项提示「更新时自动校验」，停用项提示「启用后校验」。统计表示最近一次成功预检数量，不是命中次数。升级不会用旧解析证明冒充新校验；已验证的原始下载快照仍可复用。此前「未独立计数」的已启用来源，升级后点击一次「更新订阅」重新检查。「重新加载」继续复用现有配置和缓存，不强制刷新每项订阅。

失败时按日志恢复旧配置并尝试重建旧规则。恢复只在配置与操作前或操作后模型一致时执行，忽略上游写入的数字 size 元数据；检测到其他工具的并发修改则停止恢复，保留记录供关闭并恢复。请不要手动删除 `/etc/adzero/sources-pending.json`、临时操作锁或其他恢复文件。

v0.8.1 比较匿名节的顺序与内容，忽略 libuci 删除后自动重新生成的标识；命名节仍核对实际标识。每次操作仍用显示的标识和 URL 共同核对目标，旧编号指向其他来源时拒绝修改。有其他页面未提交的后端 UCI 修改时，先在原页面保存或撤销，不让订阅变更顺带提交或丢弃这些内容。

明确选择的订阅保留在后端配置，关闭保护、标准升级和卸载不会把这些个人选择恢复为初次安装默认值。关闭时仍恢复 AdZero 自管的 DNS/TLS/代理入口。保护关闭时可以管理订阅，主开关不会因此自动开启；下次开启强制重建，避免沿用旧缓存。保护开启且没有手工拦截域名时，至少保留一个启用的订阅；需要暂停全部过滤时用临时暂停或主开关。暂停、外部托管或未完成恢复时禁止改订阅。

规则操作通过带类型的 RPC 提交给短任务启动器；慢操作在后台执行，不占住浏览器请求或 rpcd 主循环。前端持有随机任务回执，每两秒只读查询完成结果，再核对真实状态和配置。回执不包含日志、URL 或任意命令参数。重启会清空临时任务回执，持久恢复日志仍保留；状态不明时重新检测，不要重复提交。

## 返回菜单

概览快照只供展示，有效期 5 分钟，按 LuCI 登录会话隔离在当前标签页的 sessionStorage。返回时先展示上次概览，并后台重新读取；确认之前锁定修改。失败保留旧概览及重试入口，不将旧状态当作当前运行结果。首次打开、快照损坏或过期、重新登录以及禁用浏览器存储时，都可走正常实时读取路径。

规则列表不写入快照；打开规则页会重新核对列表，但已有行保留显示，核对前禁用编辑。浏览器中保存的源地址只在当前页面内存和输入框中，离开页面不持久保存这些内容。当前版本不提供流量日志、按订阅命中次数或全部 AdGuard Home 过滤语法。
