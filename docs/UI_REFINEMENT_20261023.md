# v0.18.1 界面密度与信息层级调整

本轮根据三张使用截图调整 DNS 增强、已添加规则和规则库。保留广告规则处理、代理接入及网络配置的原有后端实现。

## 页面变化

- DNS 增强在宽屏下分为「增强过滤」「上游与备用」两个工作区，手机上顺序堆叠。开关标签为主信息，解释为次级文字，适用范围与测试边界默认收起；清理待确认和状态读取失败始终直接显示。
- 用原生复选框实现可键盘操作的紧凑开关，保留焦点反馈和 44 像素操作区域。国内／国外测试结果分别展示，未测试、跳过、失败有明确文字，不仅靠颜色区分。
- 规则列表减少纵向留白，名称、数量、最近检查和操作对齐。桌面普通行实测约 72 像素；长网址单行省略，可通过键盘或点击展开完整内容。待应用标记仍在名称旁显示。
- 规则库改为连续列表，增加「全部／未添加」本地筛选，已添加项显示明确状态。添加仍只进入草稿，统一应用后生效；筛选不发起下载或修改配置。
- 自定义订阅表单默认收起，按需打开。展开状态在当前页面的后台重绘中保留。

## 交互修正

编辑增强开关、端口或设备规则时，即时更新未保存提示并禁用测试按钮，避免测试旧的保存配置。撤销至原值或成功保存后恢复测试，无需重绘正在输入的字段。添加设备聚焦名称；在「未添加」筛选下加入规则后，焦点回到筛选按钮。
