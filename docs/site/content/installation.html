先找对安装渠道，再复制命令。 AdZero 提供常规安装和两套独立公测。每套安装器都会核对固件版本、设备 target、包架构与安装包校验值；不符合就停止，不要强行混装。

第一步：看看自己的固件是否在名单中

支持的固件与版本表列出了全部精确组合。简单来说：

你的固件该用哪个安装器
OpenWrt 24.10.8 / 25.12.5、ImmortalWrt 24.10.6 / 25.12.2 的指定常规目标常规安装菜单
OpenWrt 25.12.6 / ImmortalWrt 25.12.2 的 Rockchip ARM64 或 MediaTek FilogicARM64 公测菜单
iStoreOS 25.12.6（修订号 2026102312）的 x86_64、ARMSR 或 Rockchip R6XSiStoreOS 公测菜单

三套菜单不能混用。先核对系统版本、target 和 CPU 包架构；如果固件不匹配，安装器会拒绝安装。

常规安装：OpenWrt / ImmortalWrt

适用于已经提供 SDK 构建包的五组完整目标（查看名单）。用 root SSH 执行以下一条命令：

curl -fL --proto '=https' --proto-redir '=https' https://raw.githubusercontent.com/slobys/AdZero/main/scripts/install.sh -o /tmp/adzero-install.sh && sh /tmp/adzero-install.sh --menu

进入中文菜单，选择兼容检查、安装、安装但暂不开启、升级或安全卸载。安装包按当前固件自动匹配，不需要手动输入 CPU 架构。常规发布版本为 $release（当前同样标记为 Pre-release，SDK 编译不等于所有真机认证）。

ARM64 公测：OpenWrt / ImmortalWrt 新目标

仅适用于 OpenWrt 25.12.6 或 ImmortalWrt 25.12.2 的 rockchip/armv8、mediatek/filogic 指定架构；不要把它当成任意 ARM64 的通用包。以 root SSH 执行：

curl -fL --proto '=https' --proto-redir '=https' https://github.com/slobys/AdZero/releases/download/v0.21.5-arm64-beta.1/install-arm64-beta.sh -o /tmp/install-arm64-beta.sh && sh /tmp/install-arm64-beta.sh --menu

安装器会自动选择四个原厂 SDK APK 中的匹配包，先模拟依赖安装。缺少依赖时仅尝试匹配固件的官方 HTTPS 软件源；源无法验证、依赖不齐或准备替换原系统包，就会停止。首次安装默认不启用 DNS 过滤。

iStoreOS 公测：x86_64 / ARMSR / R6XS

仅适用于 iStoreOS 25.12.6、修订号 2026102312。支持 x86_64、ARM64 ARMSR 和原厂兼容的 Rockchip R6XS，R6XS 还会核对板型。以 root SSH 执行：

curl -fL --proto '=https' --proto-redir '=https' https://github.com/slobys/AdZero/releases/download/v0.21.5-istoreos-beta.1/install-istoreos-beta.sh -o /tmp/install-istoreos-beta.sh && sh /tmp/install-istoreos-beta.sh --menu

每种设备的安装包都含 AdZero 本体及六个对应原厂依赖，安装前验证 SHA-256 和离线依赖计划。首次安装默认关闭 DNS 过滤，不自动更改原有 DNS/代理路径。

安装成功后做什么？

  1. 先确认仍能进入 LuCI / SSH，正常网站能打开。
  2. 进入 服务 → AdZero，到「过滤规则」选择列表并应用。
  3. 回到「运行概览」开启保护，再从电脑检测广告域名与正常域名。

公测版建议先安装不启用，等正常上网和原代理确认无误，再手动开启。首次试装优先使用有备用管理方式的设备，并提前备份配置。

已安装 AdZero，怎么升级？

常规渠道：安装包含 LuCI 更新功能的版本后，可以点击 Logo 旁的版本号检查更新；仅会接受与本机兼容的常规发行包。也可以重新运行常规菜单按提示升级。

独立 Beta 不走常规 LuCI 自动更新。两个 Beta 不是常规渠道的升级包；已经安装其他版本的设备不会被强制覆盖。更换渠道前请先在原渠道关闭保护、恢复网络设置并安全卸载，再按目标安装。公测版卸载与恢复。

路由器不能连接 GitHub？

可以通过可信电脑从对应的 GitHub Release 下载安装器及该固件专用压缩包，复制到路由器同一目录，然后使用菜单的 --local-dir 离线参数。仍会进行固件、target 和 SHA 校验；ARM64 公测缺失的官方依赖可能仍需可用的软件源。详见各自发行说明。

安装失败，怎么办？

先保留终端报错，不要更改 DISTRIB_ID、手动替换不匹配的 APK，也不要直接删除 DNS/代理配置。常见原因包括固件版本不一致、官方依赖源不可用、已有 AdZero 安装、备份或恢复任务仍在进行。按安装兼容问题和升级失败排查处理。
