先确认兼容范围

以下组合提供官方 SDK 构建包。固件版本、设备目标和架构必须匹配，不能只看“都是 ARM64”。

固件设备目标格式
OpenWrt 24.10.8x86/64IPK
OpenWrt 25.12.5x86/64APK
OpenWrt 25.12.5rockchip/armv8APK

其他版本、架构、ImmortalWrt 和 iStoreOS 按兼容矩阵逐步推进。安装器拒绝未匹配组合时，不要强制安装其他机型包。查看详细兼容矩阵。

首次安装

以 root 登录路由器 SSH，确认网络可用，执行：

curl -fL --proto '=https' --proto-redir '=https' https://raw.githubusercontent.com/slobys/AdZero/$release/scripts/install.sh -o /tmp/adzero-install.sh && sh /tmp/adzero-install.sh --menu

安装器核对固件与包校验值、准备依赖并备份配置。完成后进入 服务 → AdZero。也可在 发行页面 下载匹配的包；手动安装与恢复见 详细安装说明。

升级已有安装

curl -fL --proto '=https' --proto-redir '=https' https://raw.githubusercontent.com/slobys/AdZero/$release/scripts/install.sh -o /tmp/adzero-install.sh && sh /tmp/adzero-install.sh --upgrade

升级先检查安装条件，再让旧版恢复它接管的设置并替换包。过程中可能短暂重载 DNS 或当前代理；等待命令结束。安装器不会替你改写第三方软件源。

升级后用 Ctrl F5 刷新页面；在 SSH 查看实际安装版本：

apk list --installed luci-app-adzero

使用 opkg 的固件执行：

opkg list-installed luci-app-adzero

安装中断怎么办

保留终端报错并确认仍安装哪个版本、保护当前是否开启。软件源下载失败应先处理对应源，不要删除配置或反复卸载。可从 升级失败排查 继续。
