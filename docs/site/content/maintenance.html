升级前与配置备份

安装器会显示备份位置，通常在 /etc/adzero-backups/时间/config.tar.gz。请保留终端输出，并把需要的备份另存到安全位置。备份可能包含网络配置和私人列表，不要公开上传。

大版本或固件升级前，另外使用 LuCI「系统 → 备份/升级」保存系统配置。两类备份用途不同。不要用旧备份整包覆盖当前代理配置来处理一个报错。

日常维护

需要新规则时更新订阅；规则没变化时重用已有快照。升级步骤见安装与升级。统计为运行期数据，最近拦截只在内存中，不能作为长期日志备份。

升级后仍可识别旧恢复记录中明确的下载大小、计数和校验时间；不会忽略订阅、DNS 或未知选项的真实差异。已有处理后缓存仍需配置和文件摘要一致才能恢复，不能用更新但尚未应用的订阅快照冒充当前规则。

常规安装：安全卸载

先在页面关闭保护并等待恢复完成，再卸载。SSH 可以使用下方命令：只有恢复成功才继续删除插件包。如果通过独立 Beta 安装，请改用公测版卸载菜单。

使用 APK 的固件：

/usr/libexec/adzero/ctl disable && apk del luci-app-adzero

使用 opkg 的固件：

/usr/libexec/adzero/ctl disable && opkg remove luci-app-adzero

恢复失败或正在等待操作锁时，先处理原因，不强制卸载、不删 /etc/adzero/adapter.json 等恢复记录。卸载后核对原代理和普通 DNS 正常。

大规则的恢复内容单独存放在 /etc/adzero/providers/，元数据只记录摘要引用；更新和撤销仍核对原文件，兼容旧版内嵌记录。不要手动删除快照目录。代理切换时若后台操作锁忙，会在下一轮自动重试；实际适配失败则延后一分钟再试，避免连续重载。完成前不会把新路径记成已同步。

ARM64 / iStoreOS 公测版怎么卸载？

公测版优先用对应的测试版菜单选项 4 卸载，不要直接用常规版命令跳过安装标记与网络恢复检查。菜单会先关闭过滤并尝试交还 AdZero 管理的 DNS/代理配置，失败时保留记录并停止删除软件包。

无论是 OpenWrt / ImmortalWrt ARM64 Beta 还是 iStoreOS Beta，都可以重新运行同一条统一安装命令。助手会重新识别本机固件，进入当时对应的 Beta 菜单，再选择「安全卸载」。路由器重启后 /tmp 的旧脚本可能不存在，重新从官方 GitHub 下载即可。

测试版卸载默认保留共用系统依赖和配置备份，不会自动回退整个路由器固件。若提示恢复未完成、操作锁占用或找不到安装标记，请先停止，保留报错，不要强行删除插件或相关 DNS 文件。

配置与依赖的保留

不要为了卸载 AdZero 顺手删除其他插件共用的 DNS、代理或软件包依赖。需要彻底清理配置时，先保留备份并确认不再需要恢复；不要手动删除仍被 dnsmasq 引用的文件。
