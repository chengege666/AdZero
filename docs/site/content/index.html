第一次使用 AdZero？只需一条安装命令：它会自动检测 OpenWrt、ImmortalWrt 或 iStoreOS，使用同一个正式版本和中文菜单。首次安装保持保护关闭，确认网络正常后再开启过滤。

三步开始使用

  1. 确认固件与设备架构：查看三个固件共用的安装条件与依赖范围。
  2. 一键安装：以 root SSH 运行统一命令，自动选择固件与安装包。
  3. 开启并验证过滤：选规则、应用，在连接路由器的电脑上做 DNS 效果检测。

AdZero 是做什么的？

AdZero 是装在软路由上的 DNS 域名广告过滤插件，直接从 LuCI 管理。它用 adblock-fast 处理过滤列表，也可以配合受支持的代理，无需另外登录或安装管理 App。

它擅长拦广告、追踪域名的解析，不等于浏览器广告扩展：与内容共用域名的视频广告、设备自己的加密 DNS 或绕过路由器的流量，未必能拦截。页面显示的 DNS 请求拦截占比，也不是网页广告拦截率。

发行和测试：当前正式版本为 v$version，三个固件共用同一入口。软件包安装与隔离测试不代替每台真实设备的 LAN、DNS、代理和恢复验收。
