先了解过滤范围

AdZero 是 OpenWrt 上的 DNS 域名过滤插件，集成在 LuCI，使用 adblock-fast 处理列表，并与受支持的代理协作。无需额外登录或安装 AdGuard Home。

它能阻止广告、追踪域名的解析；无法去除与正文共用域名的视频广告，也不能像浏览器扩展那样隐藏网页空白。设备直接使用加密 DNS 或绕过路由器时，可能不经过这里。

版本与验证范围：本手册对应 v$version 测试版。构建和隔离测试通过不等于所有固件、代理版本和真实终端都已验证。查看支持范围。
