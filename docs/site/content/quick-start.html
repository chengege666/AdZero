先让原网络可用

如果使用 ARM64 或 iStoreOS 独立 Beta，首次安装默认不会开启广告过滤。先确认原有网络、SSH、LuCI 和代理都正常，再手动开启；不要一安装就修改所有 DNS 设置。

先确认当前代理独立工作正常。只保留一个正在使用的代理内核；无需为了 AdZero 更换节点或 DNS 引擎。若已有 AdGuard Home 接管 DNS，先停止对应服务，避免重复接管。

选规则并开启保护

  1. 打开 服务 → AdZero，等待读取当前状态。
  2. 进入「过滤规则」，选择需要的列表。先从少量列表开始，避免相近列表大量重复。
  3. 有「待应用」提示时，点击「应用并重新加载」，等待任务结束。
  4. 回到「运行概览」，开启保护。首次可能需要下载规则，请勿重复点击。
  5. 核对「当前接入」是否与正在使用的代理一致。无代理时可以是「路由器 DNS」。

普通广告过滤无需打开「DNS 增强」；自动分流也是可选项。先沿用默认设置完成验证。

在电脑验证效果

  1. 在「运行概览」点击「开始检测」。
  2. 复制页面生成的查询命令，在连接该路由器的电脑执行；使用该路由器作为 DNS。
  3. 等待页面核对测试标记、被拦截域名和正常域名的应答。

也可以用下面的查询做对照，将 192.168.2.1 换成自己的路由器地址：

nslookup -type=A doubleclick.net 192.168.2.1
nslookup -type=A www.baidu.com 192.168.2.1

先在「访问控制」查询广告域名是否命中当前规则。命中的域名通常返回空答案或阻断地址；正常域名应能解析。列表不同，测试域名未必总会命中，以当前规则查询和页面检测结果为准。

平时怎么操作

网站异常先临时暂停对比，再去访问控制检查域名。不要仅因为一个网页打开慢就更换全部 DNS、清空规则或重装插件。
