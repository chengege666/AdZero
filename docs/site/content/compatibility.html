怎么查看自己的固件信息？

用 root 登录路由器 SSH，先执行只读命令：

cat /etc/openwrt_release

重点查看 DISTRIB_ID（固件）、DISTRIB_RELEASE（版本）、DISTRIB_TARGET（设备目标）、DISTRIB_ARCH（包架构）。iStoreOS Beta 还会核对 DISTRIB_REVISION；即使 CPU 相同，也必须和上面精确对应。

需要核对实际包管理器时，可尝试 apk --print-arch。旧的 IPK / OPKG 固件不使用 APK；安装脚本会自行判断。如果目标不在表中，请提交兼容需求，不要改掉固件标识来绕过检查。

公测前先记住三件事

  1. 先备份，有救援方式。建议从非唯一生产路由器开始，保持本地 SSH / 有线管理可用。
  2. 先安装，不急着开启。Beta 首次推荐安装但关闭过滤；确认网络正常后再手动开启，检查 DNS 和代理。
  3. 别用稳定版更新按钮升级 Beta。两个 Beta 都是单独的发布渠道，当前未加入常规 LuCI 在线更新白名单；已安装其他版本时先按原渠道安全卸载。
