默认地址与路径

在「运行概览 → DNS 与分流」展开设置，编辑国内、国外 DNS。每组第一条是当前地址，后面是备选库。

分组默认当前地址默认备选
国内223.5.5.5119.29.29.29
国外1.1.1.18.8.8.8

每组一至八个不同的 IP，支持有效 IPv4/IPv6。这里使用标准 53 端口：国内 UDP、国外 TCP；不接受 DoH/DoT 网址、域名或任意端口。国内、国外当前地址不能相同。

修改与应用

  1. 每行输入一个地址，调整顺序选择当前项。
  2. 保存到待应用，核对其他规则或分流草稿。
  3. 点击一次「应用并重新加载」。

备选地址默认不自动参与查询；显式启用同组备用后才按条件切换。恢复默认也先进入草稿，不立即改网络。

自动分流要不要开

普通广告过滤无需开启自动分流。需要由 AdZero 设置国内直连、国外经当前受支持代理的 DNS 与分流时，再开启。关闭时保留个人地址库；设置通常在下一次开启自动分流时使用。

PassWall 保留原有 dnsmasq 或 ChinaDNS-NG 引擎和原生节点、分组策略。AdZero 不保证任意代理引擎或自定义 ACL 都支持自动分流；无法确认时会提示，不强制转换引擎。

怎样判断解析速度

先看概览当前路径的正常 DNS 应答耗时，再用上游测试比较同组地址。第一次查询和命中缓存的耗时不同，不要只看一次测试就换地址。

DNS 返回了地址或 NOERROR，不等于地址可靠、代理出口正确或网页可访问。怀疑污染时需对照可信路径；切换后坏缓存与旧连接问题见解析异常。
